# 「契响卷灵」进化族系 V3 返工说明

## 返工结论

V3 仅重构幼年体基础剪影，保留 V2 已通过的履契拳师、万策卷贤、Y 形分支构图和色彩血统。幼体不再借用犬猫宠物骨架，而成为由合同卷筒、折叠页束、条款分段、缝线与蜡封组成的悬浮纸契生命。

## 幼年体：诺卷仔 V3

- 阶段：幼年体
- 属性：契约／成长
- 性格：好奇、轻快，会通过卷边开合和上下弹跳回应旅伴。
- 成长条件：写下一个真实可执行的小清单，并完成其中第一项；完成回响逐渐点亮环身条款。
- 能力「回响墨迹」：完成一项清单时，斜绕身体的条款带亮起勾印，纸簧便获得一次轻盈弹跳。
- 图鉴文案：它没有兽类的骨骼，只有被履行的条款会让卷边舒展，托起好奇的独眼。

## 抽象轮廓结构

- 主体：一根竖向合同卷筒嵌套在松开的螺旋页束中，形成悬浮灯笼／逗号形体块。
- 顶部：只有一片向单侧扫出的宽大页帆；另一侧仅为短小破折角，不构成成对耳朵。
- 底部：单个中央卷纸簧作为弹跳支点，身体略微离地；不存在腿、爪或后肢。
- 侧面：条款带斜向绕体并在侧面分成短页签；没有从后方伸出的动物尾巴。
- 面部：纸层暗隙中只有一只偏置绿色发光眼，另一侧是绿色勾形符文；无对称宠物脸。
- 契约识别：珊瑚蜡封位于卷筒中央作为生命核心；靛青缝线固定外层页束；勾选格与横向条款分段直接构成身体。

## 小动物般的生命感

诺卷仔的可爱与行动感来自单眼凝视、页帆倾角、纸簧压缩、卷边呼吸式开合、悬浮摆动和条款页签飘动，不依赖耳朵、四肢、兽吻、尾巴或犬猫姿态。

## 两条完全体分支

### 履契拳师

- V2 不变量保持：全头由交叠羊皮纸绷带包覆，靛青暗缝中仅露绿色发光双眼。
- 巨型契纸拳套、错步压低重心和连续勾印保持清楚拳击识别。
- 幼体的螺旋页束可拉长为全身缠带，中央卷筒可卷紧为拳套，纸簧弹力转化为行动爆发力。

### 万策卷贤

- V2 不变量保持：书肩、页冠、书袍、书脊、装订结构和胸前主书板共同组成大学者。
- 幼体的条款分段可裁整为书页，缝线可延展为书脊，外层页束可展开为书袍与页冠。
