# 「契响卷灵」进化族系 V4 头部统一说明

## 修订范围

V4 以 V3 为直接编辑目标，仅替换万策卷贤的头部及头颈衔接所需的极小区域。诺卷仔、履契拳师、万策卷贤身体、Y 形分支、背景、色彩、光效、角色位置和整体比例保持 V3 方向。

## 万策卷贤新头部

- 去除：动物鼻口、毛发感面片、兽耳、猫犬脸型与普通宠物表情。
- 侧面结构：两块微弧小型书封板围出头部书匣轮廓，以古金护角连接页冠。
- 正面结构：多层横向页缘构成沉稳书页额罩，中央靛青缝线连接头顶与眉部。
- 生命核心：正面中央为深靛青页缝，两只柔和的绿色发光眼从纸层暗面中显现；无鼻、无嘴。
- 情绪表达：眼形平缓、光晕柔和，以稳定凝视表达沉静、睿智和友善，不使用尖牙、空洞眼窝或恐怖阴影。
- 分支区分：学者头部是有秩序的“合页书匣／层叠册页面具”，依靠书封侧板、页缘和中央装订线识别；不是履契拳师的交错木乃伊缠带。

## V3／V4 不变量对照

- 诺卷仔：设计、位置、尺寸、姿态和光效保持。
- 履契拳师：全头纸封、绿色双眼、拳击姿态、拳套、位置和尺寸保持。
- 万策卷贤身体：页冠、书肩、书袍、胸前清单板、珊瑚蜡封、手势、页带尾、身体比例和大学者剪影保持。
- 构图：三个角色仍位于左、右上、右下，绿色 Y 形分支关系保持。
- 背景与色彩：浅暖象牙背景、羊皮纸、青柠光、珊瑚蜡封、靛青装订与古金护角保持。
