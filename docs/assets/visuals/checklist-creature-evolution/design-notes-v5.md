# 「契响卷灵」V5 严格局部合成说明

## 结果

V5 以 V3 的 1693×929 原始像素作为不可变底图，仅将 V4 已通过的万策卷贤书页头部合成到头部椭圆区域。V1 至 V4 均保留。

## 合成范围

- 允许椭圆中心：`(1205, 600)`
- 水平半径：`105 px`
- 垂直半径：`84 px`
- 羽化内圈比例：`0.82`
- 实际差异像素包围框：左上 `(1101, 517)`，右下 `(1308, 683)`
- 实际差异像素数：`26,855`
- 允许矩形 `(1100,516)–(1310,684)` 外差异像素：`0`
- 允许椭圆外差异像素：`0`

椭圆范围覆盖万策卷贤头壳及必要的窄边缘融合区；胸前蜡封、清单板、书肩、手势和身体均位于差异边界之外或保持 V3 原始像素。

## 头部设计

- 无动物鼻口、兽耳、毛发、猫犬脸型或普通宠物表情。
- 头部由书封侧板、层叠页缘、中央靛青装订线和深色页缝构成。
- 两只柔和绿色眼睛从页缝暗面显现，保持沉静、睿智与友善。
- 结构是有秩序的合页书匣／册页面具，不复制拳手的木乃伊绷带包头。

## 不变量证明

V5 从 V3 位图副本开始生成，合成程序只在定义的头部椭圆内写入像素。保存后重新逐像素比较 V3 与 V5：

- 尺寸完全相同：`1693×929`
- 实际差异边界完全落在允许区域内
- 允许区域之外逐像素一致
- 幼年体、拳手、大学者身体、Y 形箭头、背景、构图、位置、尺寸、色彩和光效保持 V3 原始像素

- 通过：书封侧板与页冠连接自然，无重影或错位。
- 通过：页冠连续，无断裂页片或异常色带。
- 通过：头部与胸前蜡封之间无重复边缘。
