# 全物种通用宠物蛋标准模板

## 返工结论

宠物蛋统一采用“标准圆壳恐龙蛋”模板。所有物种永久共用同一轮廓、硬壳材质、花纹几何、斑块数量、斑块尺寸、斑块分布、观察角度和孵化状态逻辑；物种归属只能通过四个颜色槽的取值区分。

上一版的卷页冠、纸簧底座、装订凸起、茧形开口、合同条款、勾选格、蜡封和缝线均不进入标准模板。

## 唯一标准轮廓

- 模板名称：标准圆壳恐龙蛋
- 几何标识：`EGG_STD_01`
- 总体形态：饱满、完整闭合、圆润连续的经典恐龙蛋
- 轴向关系：近旋转对称，顶部略窄但保持圆钝，底部较宽且连续收圆
- 表面连续性：顶部、侧腹与底部之间不得出现平台、平底、颈部、尖冠、卷边、开口、接缝脊、凸环、底座或附着物
- 多视角不变量：正面、侧面和正面三分之四视角使用同一蛋体，只允许相机旋转和对应的高光变化

未来所有宠物蛋直接复用 `EGG_STD_01`，不得按物种修改高宽比、曲率、重心、顶部圆度或底部圆度。

## 统一硬壳材质

- 材质标识：`SHELL_SEMIMATTE_01`
- 材质类型：圆润半哑光天然硬蛋壳
- 微观特征：细微蛋壳孔隙、极浅矿物颗粒、柔和随机色差
- 高光：一处宽而柔的面光高光，不形成玻璃反射或金属亮边
- 禁用材质感：羊皮纸、纸张、布料、皮革、金属、石头、陶瓷、玻璃、书本或拳带

所有物种共享同一材质参数和微表面密度，不能借材质变化表达物种。

## 固定通用花纹模板

- 花纹标识：`SPOTMAP_STD_01`
- 主斑：五块圆润有机大斑块
- 副斑：四块圆润有机中斑块
- 微光点：十六枚细小圆点
- 轮廓特征：自然、柔和、不规则，但不形成符号、脸或可读图标
- 曲面关系：花纹作为固定表面色图包覆蛋壳，随曲率产生透视、遮挡与缩短
- 边缘关系：斑块边缘不做凸起、压印、雕刻、描边或发光轮廓

以下项目对所有物种固定不变：

- 五块主斑的形状、面积、朝向和表面位置
- 四块副斑的形状、面积、朝向和表面位置
- 十六枚微光点的直径、间距和表面位置
- 各类斑点的数量比例与视觉层级
- 蛋壳孔隙、矿物颗粒和高光模型

未来新宠物蛋不得重新排列花纹、增加或删除斑点，也不得使用合同线、勾选格、蜡封、缝线、书页、拳带、字母、数字、徽章或物种图标。

## 全宠物蛋固定颜色槽

| 槽位 | 固定作用 | 允许变化 | 禁止变化 | 契响配色 |
| --- | --- | --- | --- | --- |
| `base` | 整颗蛋壳的基础颜色 | 颜色值 | 材质、孔隙、高光、轮廓 | `#E8D8B7` 暖象牙 |
| `primary_spot` | 五块有机大斑 | 颜色值 | 数量、形状、尺寸、位置 | `#283C58` 深靛青 |
| `secondary_spot` | 四块有机中斑 | 颜色值 | 数量、形状、尺寸、位置 | `#CF6B55` 暖珊瑚 |
| `hatch_glow` | 十六枚固定微光点及其局部光晕 | 颜色值与状态强度 | 数量、直径、位置、光效类型 | `#B8D94A` 青柠绿 |

### 色量层级

- `base` 始终占绝对主导，保证第一眼仍是自然蛋壳
- `primary_spot` 提供主要色块对比
- `secondary_spot` 只用于较小面积的色彩平衡
- `hatch_glow` 仅存在于十六枚固定小点及贴壳光晕，不形成线、符号或 UI 进度条

## 三种孵化状态

三种状态必须使用同一正面三分之四观察角度、同一轮廓、同一花纹投影、同一硬壳材质、同一高光和同一落地阴影。只允许改变 `hatch_glow` 的亮度、饱和度和局部光晕强度。

### 未唤醒

- 十六枚固定微光点亮度约为 15%
- 微光点表现为低饱和黄绿色小点
- 无超出点位边缘的明显光晕
- 蛋壳、靛青主斑和珊瑚副斑保持标准颜色

### 回响积累

- 同一十六枚微光点亮度约为 55%
- 青柠饱和度提高
- 每个光点产生不超过自身直径两倍的柔和贴壳光晕
- 蛋体与花纹几何完全不变

### 临近孵化

- 同一十六枚微光点亮度达到 100%
- 光点呈清晰青柠色，并形成克制的统一贴壳柔光
- 光晕不得遮盖硬壳孔隙和自然斑块
- 蛋仍完整闭合，不出现裂纹、开口、碎片、烟雾或幼年体

## 制作与换色规范

未来新增宠物蛋时：

1. 直接复制 `EGG_STD_01`、`SHELL_SEMIMATTE_01` 与 `SPOTMAP_STD_01`
2. 只填写 `base`、`primary_spot`、`secondary_spot`、`hatch_glow` 四个颜色值
3. 沿用三状态的 15%／55%／100% 微光强度
4. 不增加任何物种专属几何、图标、花纹、材质或孵化动作

## 最终目视核验

- 多视角图第一眼明确为圆润饱满的经典恐龙蛋
- 三视角顶部和底部均连续圆滑，无卷页冠、底座、接缝或开口
- 大斑、中斑和微光点服从曲面透视，无 UI 图标感
- 三状态图使用相同观察角度与相同花纹投影
- 三状态只改变固定青柠光点及光晕强度
- 两图无文字标签、水印、商标、宠物、幼年体、裂壳、碎片或既有 IP 标识
- 模板可通过替换四个颜色值直接生成其他物种宠物蛋
