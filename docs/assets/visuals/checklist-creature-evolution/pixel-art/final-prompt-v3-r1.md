Input images: Image 1 是唯一编辑目标。

Primary request: 只编辑 Image 1 的空白背景和四个角色脚下的落地阴影。把整个背景替换为单一、完全均匀、不透明的暖白纯色，视觉上接近 #FFF8E8。把现有柔化落地影改成极简的单色硬边粗像素块。除背景与落地影之外，不得改变任何内容。

Background edit: 从画布左上角到右下角，每一个空白背景像素使用完全相同的一种暖白色。禁止任何中心亮、边缘暗、角落偏色、径向渐变、线性渐变、光晕、暗角、纸张质感、噪声、颗粒或连续明暗变化。背景只能有一个纯色色值，不能使用第二种近似暖白。

Strong invariants: 四个角色与全部进化箭头是强不变量，必须与 Image 1 保持完全一致。锁定四角色的数量、像素级位置、尺寸、轮廓、姿态、左右分支布局、箭头形状、勾选节点、主配色以及主体内部每一个粗像素细节。锁定初始体、中间体、格斗型、祭司型的人设；锁定米黄卷轴、深色缝线、绿色眼部、橙红徽章、绿色勾选、拳套、法袍、冠饰、清单板和卷曲纸尾。不要重绘、移动、缩放、裁切、补画或重新解释主体。

Pixel discipline: 新背景与新影子必须匹配 Image 1 的同一超粗方形像素网格。整个成品不得出现抗锯齿、柔和笔刷、连续渐变、平滑阴影或半透明边缘。

Constraints: change only the background and ground shadows; keep every character and arrow unchanged. 精确四个角色，无新增元素。无文字、标题、品牌、签名、水印或第三方角色。不透明暖白背景。
