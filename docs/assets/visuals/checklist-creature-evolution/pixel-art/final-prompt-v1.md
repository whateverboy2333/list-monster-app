# Checklist Creature Pixel Evolution V1 — Final Prompt

Use case: stylized-concept

Asset type: 清单怪兽 APP 的四形态角色视觉概念展示图

Input images: Image 1 是角色设定与形态关系参考；严格保留四个角色的身份、数量、关键服装与标志，但把画面重绘为像素艺术，不复制其平滑 3D 渲染质感。

Primary request: 在同一张横向画面中完整呈现同一只“清单卷轴怪兽”的四个形态，且只有这四个角色。沿用参考图的关系与易读布局：左侧小型悬浮初始体，中央较大的卷轴人偶中间体，右上短壮格斗型进化体，右下宽袍祭司型进化体。各角色之间留出清晰间距，不遮挡。

Subject details: 四形态统一使用米黄羊皮卷轴/绷带身体、明显深青黑缝线、深色脸部开口与绿色发光眼睛或面罩、橙红色蜡封/圆形徽章、散布的绿色勾选符号；手臂、腿或尾巴由卷曲纸带构成。初始体是小巧悬浮的兜帽卷轴团，带尾端纸带；中间体为直立卷轴人偶，顶部展开成弧形纸卷，双臂是对称卷曲清单纸带；格斗型短而壮，缠满卷轴绷带，佩戴巨大圆厚拳套，双腿岔开、双拳举起的战斗姿态，卷曲长纸尾；祭司型穿宽大深青/墨绿色法袍并带暖金镶边，头后是纸页扇形冠饰，正面双手前方悬挂一块清晰的米黄清单板，板上只画三个绿色方框勾选图形，另有卷曲纸带尾巴。

Style/medium: 中等精细度彩色像素画角色设定图；明确可见的像素块与阶梯状边缘，干净有控制的深色像素轮廓，约 32-bit 复古 RPG 怪物立绘的细节密度；每个角色都有足够的绷带层次、纸张折痕、缝线和徽章细节，但不能像超低分辨率火柴人。不要抗锯齿感，不要平滑矢量边缘。

Composition/framing: 横向 16:9，全身展示，四个形态尺寸层级与参考图相近；初始体最小，中间体居中，右侧上下两个进化分支。可以用极简的绿色像素勾选节点与细线暗示进化关系，但它们只是图形符号，不得形成文字，也不得遮挡角色。

Scene/backdrop: 简洁暖白到极浅米色的纯净背景，可有非常轻的像素化落地阴影；无场景道具、无边框、无装饰噪点。

Lighting/mood: 统一的柔和左上方暖光，绿色眼睛和勾选符号有克制的荧光像素高光；可爱、机灵、略带冒险感，不恐怖。

Color palette: 统一限色板：米黄羊皮纸、砂金高光、深青黑缝线和阴影、墨绿/深青法袍、酸橙绿色发光、橙红蜡封；四形态像素密度、明暗层级和材质表现一致。

Constraints: 角色数量必须精确为四；四个都属于同一角色家族；保留参考图关键轮廓和所有标志性元素；祭司型必须正面持清单板；格斗型必须有拳套和战斗姿态；所有角色全身可见；输出为完整彩色像素画。

Avoid: 任何第五个角色或宠物；遗漏任一形态；文字、字母、数字、标题、说明标签、品牌标识、水印、签名；第三方角色；平滑 3D 渲染、黏土模型、摄影、水彩、油画、柔焦、矢量扁平插画；过度写实恐怖木乃伊；透明背景；裁切角色；颜色与参考图明显偏离。
