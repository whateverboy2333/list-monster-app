Composition/framing invariants: 严格维持 Image 2 的横向 16:9 四形态设定板：左侧小型悬浮初始体、中央直立卷轴中间体、右上短壮格斗型、右下宽袍祭司型；恰好四个角色，全身可见。保留左到中的水平绿色进化箭头，以及从中央分叉到右上和右下的绿色箭头与方框勾选节点。角色位置、朝向、动作和尺寸层级基本不变，不新增、不遗漏。

Character invariants: 四形态仍必须一眼识别为同一家族。保留米黄卷轴/绷带身体、粗深青黑缝线、黑深色脸部开口、酸橙绿色发光眼部、橙红圆形蜡封徽章、绿色勾选、卷曲纸带肢体和尾巴。初始体保留兜帽卷轴团与短尾；中间体保留头顶开卷、直立身体和左右对称卷曲纸带臂；格斗型保留短壮身材、两个巨大圆厚拳套、双腿岔开的战斗姿态与纸尾；祭司型保留扇形纸页冠、宽大深青法袍、正面米黄清单板和纸带尾，清单板只保留三个大号绿色方框勾选图形。

Pixel construction: 使用明确的 8-bit/16-bit 大型角色 sprite 语言。轮廓由 1–2 个逻辑像素厚的深色硬边构成；曲线以大台阶分段；五官和符号由少量大方块拼成。每个卷轴只用宽色带表示层次，不画细纸纹；缝线仅保留关键的粗短线；法袍仅保留大色块边缘与少量金色块，不画细花纹；拳套由几块大明暗面塑造。所有落地阴影也必须是少量横向粗像素块。

Color palette: 全图共享约 16–20 个主色。每种主要材质最多两个主体明暗色，外加最多一个极少量高光色。核心色仅为暖白背景、米黄/浅砂金纸张、深棕阴影、深青黑轮廓、深青/墨绿法袍、酸橙绿眼部与勾选、橙红徽章、少量暖金。禁止连续渐变和多级细腻塑形。

Lighting/mood: 统一左上方块面光照，可爱、清楚、高辨识度；绿色发光只能用少量硬边亮绿方块和一圈深绿方块表达，绝不使用柔光晕。

Scene/backdrop: 纯净暖白或极浅米色背景，仅保留稀疏、硬边、粗像素落地影；无场景道具、无边框、无装饰噪声。

Constraints: v3 的基础像素块必须比 Image 2 明显大一个等级，细节与色阶必须明显更少；正常显示时无需放大即可一眼看见整幅图由巨大规则方格构成。优先保留大轮廓、眼睛、徽章、勾选、拳套、祭司冠与清单板；删除一切非必要细纹。无文字、字母、数字、标题、说明标签、品牌标识、水印、签名或第三方角色。
