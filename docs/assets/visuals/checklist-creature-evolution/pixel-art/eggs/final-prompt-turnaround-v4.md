# 宠物蛋三视角 v4 最终提示词

## 编辑目标

以 `egg-turnaround-pixel-v3.png` 为编辑目标，只替换中间蛋。将其中间窄侧蛋
改为完整、饱满的正面或轻微 3/4 宠物蛋；左蛋、右蛋、画布、间距和背景均为
强不变量。

## 左右强不变量

左蛋和右蛋必须保持原有像素画轮廓、位置、宽高、图案、颜色、斜带、蜡封及
接地影，不移动、不缩放、不重绘、不简化。画面仍只含三枚横向排列的同款蛋。

## 中间蛋

中间蛋不得再呈窄侧、侧后或局部形态。其完整蛋形宽高须与左右蛋平均值一致，
保持相同视觉重量，并完整显示：

- 象牙白蛋壳；
- 石灰绿眼环；
- 带一个白色高光的深蓝眼芯；
- 绿色勾选；
- 深蓝虚线缝线；
- 向右上倾斜的米色斜带；
- 橙红蜡封；
- 浅色/白色短横和深蓝短横。

中间蛋采用与两侧相同的有限色板、每种材质 2–3 档块面明暗、轮廓粗细、
方形像素尺度和一至两档浅沙色接地影，不得更窄、更小、更浅或像另一款蛋。

## 像素约束

采用粗颗粒低分辨率像素画、大方形像素、阶梯曲线和清晰硬边。禁止连续渐变、
抗锯齿、模糊、羽化、边缘混色、光滑伪 3D 和高清纹理。背景为不透明、均匀
的暖象牙白，接近 RGB(254,250,236)，四边保留空白。禁止透明背景、文字、
标签、水印、标志、品牌、边框、额外物体和第三方角色。
