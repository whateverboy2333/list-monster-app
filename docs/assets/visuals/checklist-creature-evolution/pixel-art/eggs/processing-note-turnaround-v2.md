# 蛋形态三视角 v2 处理说明

## 产物

- 文件：`egg-turnaround-pixel-v2.png`
- 尺寸：1728×972
- 逻辑网格：192×108
- 放大倍率：9×9
- 完整 PNG 唯一 RGB 数：18
- 背景：RGB(254,250,236)

## 处理

先针对 v1 左右视角近似的问题进行一次定向图像生成，明确指定左前 3/4、
窄侧视、右前 3/4 三种视角及相反的符号位置和缝线绕向。随后以最近邻降至
192×108，共用固定 22 色上限调色板做确定性最近色量化，不使用抖动，再以
最近邻整数放大 9 倍。最终图实际使用 18 种 RGB；四周安全留白统一写为目标
背景色。未覆盖 v1 文件。

## 数值检查

- 完整 PNG：18 种唯一 RGB，低于 24 色上限。
- 每个 9×9 输出块内部颜色一致，确认同一最近邻网格。
- 四条最外边非背景像素数：0。
- 左上 400×100、左下 400×72、左侧 60 像素条、右侧 60 像素条：
  各自唯一 RGB 均为 1，且均为 RGB(254,250,236)。

## `view_image` 目视检查

通过。左蛋的眼环、对勾和封印偏左，缝线位于远端右侧；中蛋轮廓明显收窄，
只保留装饰侧面薄片；右蛋的眼环与封印偏右，缝线位于远端左侧。左右不是复制，
旋转方向可由符号位置直接辨认。象牙白蛋壳、青柠绿眼环、深蓝眼睛与缝线、
绿色对勾、米色腰带、橙红封印和彩色小条均保留。轮廓、材质色阶和阴影均为
硬边像素块，无文字、水印、品牌或额外物体。
