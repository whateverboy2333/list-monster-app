# 宠物蛋三视角 v3 最终提示词

## 参考图职责

- 新造型参考图：绝对优先决定三枚蛋的数量、横向布局、观察角度、图案位置、
  斜带、蜡封及短横颜色。
- `egg-turnaround-pixel-v2.png`：仅用于既有粗像素尺度和硬边表现。
- `checklist-creature-pixel-evolution-v3-r3.png`：仅用于清单怪兽像素风格基线。
- 新造型参考与 v2 冲突时，以新造型参考为准。

## 画面与视角

在 16:9 横向画布中仅放置三枚同款宠物蛋，等距横排，无其他物体。

- 左侧蛋：较完整的正面偏左 3/4 视角。石灰绿眼环完整位于左上朝前面，
  深蓝虚线缝线沿右侧向下弯曲；绿色勾选、米色斜带、橙红蜡封和两组短横
  均服从新参考。
- 中间蛋：明显更窄的侧后/窄侧视角，与两侧一眼可区分。石灰绿眼环只能在
  最左边缘露出部分薄片；橙红蜡封只能在左下边缘露出部分薄片。深蓝虚线
  缝线位于上部中间曲面，并保留新参考中的绿色勾选和米色斜带。
- 右侧蛋：较完整的正面偏右 3/4 视角。石灰绿眼环和深蓝眼芯仍位于新参考
  所示的左上朝前面，深蓝虚线缝线偏右；勾选、斜带、蜡封及短横位置均服从
  新参考。轮廓必须明显宽于中间蛋，并与左侧蛋的角度可区分。

## 图案与颜色

保留象牙白蛋壳、石灰绿眼环、带一个清晰白色高光的深蓝眼芯、绿色勾选、
深蓝虚线缝线、向右上倾斜的米色斜带和橙红扇贝边蜡封。斜带靠中部的一组
短横必须为浅色/白色，另一组必须为深蓝，不得把浅色短横改为绿色。

## 像素约束

采用粗颗粒低分辨率像素画：大方形像素、阶梯曲线、清晰硬边、极少量平涂色，
每种材质仅 2–3 档块面明暗。禁止连续渐变、抗锯齿、模糊、羽化阴影、
边缘混色、光滑伪 3D 和高清纹理残留。接地影仅使用 1–2 档浅沙色硬边像素块。
背景为完全均匀、不透明的暖象牙白，接近 RGB(254,250,236)，四边保留充足
空白。禁止透明背景、文字、字母、标签、水印、标志、品牌、边框、额外角色
和第三方角色。
