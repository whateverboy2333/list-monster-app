# 宠物蛋三视角 v3 处理说明

## 输出参数

- 文件：`egg-turnaround-pixel-v3.png`
- 输出尺寸：1728×972
- 逻辑网格：192×108
- 放大倍数：9 倍；每个逻辑像素对应 9×9 输出像素块
- 完整 PNG 唯一 RGB 数：18
- 背景：RGB(254,250,236)，不透明

## 生成与量化

使用内置图像生成能力，以新造型参考优先确定三枚蛋的角度、图案位置和短横
颜色；v2 与怪兽基线仅约束粗像素风格。生成结果以最近邻缩至 192×108，
再使用与 v2 一致的固定有限调色板逐像素最近色量化，全程不使用抖动。
量化后以最近邻整数放大 9 倍至 1728×972，并将安全留白统一为目标背景色。
未覆盖 v1/v2，未修改任何发光状态文件。

## 数值检查

- 完整 PNG 唯一 RGB 数为 18，满足不超过 24 色。
- 所有 9×9 基础块内部均为同一 RGB。
- 四条最外边非背景像素数为 0。
- 左上 400×100、左下 400×72、左侧 60 像素条和右侧 60 像素条的唯一
  RGB 数均为 1，且均为 RGB(254,250,236)。

## `view_image` 检查

通过。画面仅有三枚同款蛋且横向排布与新参考一致。左蛋为较完整正面偏左
3/4；中蛋轮廓明显收窄，石灰绿眼环只在左上边缘部分可见，橙红蜡封只在
左下边缘部分可见；右蛋为较完整正面偏右 3/4，三者可直接区分。蛋壳、眼环、
带白色高光的深蓝眼芯、绿色勾选、深蓝虚线缝线、米色斜带与橙红蜡封均保留。
斜带中部短横为浅色/白色，另一组为深蓝。主体和一至两档浅沙色接地影均为
硬边粗像素块，无渐变、模糊、抗锯齿、边缘混色、伪 3D、高清残留、文字、
水印、品牌或第三方角色。
