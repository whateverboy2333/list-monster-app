# 宠物蛋三视角 v4 处理说明

## 输出参数

- 文件：`egg-turnaround-pixel-v4.png`
- 输出尺寸：1728×972
- 逻辑网格：192×108
- 放大倍数：9 倍；每个逻辑像素对应 9×9 输出像素块
- 完整 PNG 唯一 RGB 数：17
- 背景：RGB(254,250,236)，不透明

## 处理

使用内置图像生成能力定向生成完整中间蛋，再采用既有固定有限调色板做确定性
最近色量化，不使用抖动。最终合成以 v3 为逻辑像素基底，仅替换中间安全区域；
左右蛋直接保留 v3 原像素。合成后以最近邻整数放大 9 倍。未覆盖 v1–v3，
未修改任何发光状态文件。

## 逻辑轮廓与一致性

- 左蛋：X=16–61，Y=19–87，轮廓 46×69 逻辑像素。
- 中间蛋：X=74–118，Y=19–87，轮廓 45×69 逻辑像素。
- 右蛋：X=134–178，Y=19–87，轮廓 45×69 逻辑像素。
- 左右平均宽度为 45.5，中间宽度差为 0.5；三者高度均为 69。
- 中间安全区域之外与 v3 逐像素比较，差异像素数为 0，确认左右蛋保持。

## 数值检查

- 完整 PNG 唯一 RGB 数为 17，满足不超过 24 色。
- 所有 9×9 基础块内部均为同一 RGB。
- 四条最外边非背景像素数为 0。
- 左上 400×100、左下 400×72、左侧 60 像素条和右侧 60 像素条的唯一
  RGB 数均为 1，且均为 RGB(254,250,236)。
