# 宠物蛋三视角 v6 处理说明

## 输出参数

- 文件：`egg-turnaround-pixel-v6.png`
- 输入：`egg-turnaround-pixel-v5.png`
- 输出尺寸：1728×972
- 逻辑网格：192×108
- 放大倍数：9 倍；每个逻辑像素对应 9×9 输出像素块
- 完整 PNG 唯一 RGB 数：17
- 背景：RGB(254,250,236)，不透明

## 处理

先使用内置图像生成能力，依据参考图中间蛋生成“完整宽蛋体上的侧视投影花纹”。
确定性后处理以 v5 为逻辑像素基底，清除中间蛋旧正面花纹并恢复为既有壳色，
再仅提取生成结果中的侧视花纹色块。所有覆盖限定在原中间蛋非背景区域内，
使用既有调色板做无抖动量化，最终以最近邻整数放大 9 倍。

## 保护与尺寸检查

- 左右对应区域相较 v5 的输出像素差异数：0。
- 中间蛋背景掩码相较 v5 的差异逻辑像素数：0。
- 中间接地影相较 v5 的输出像素差异数：0。
- 三蛋轮廓：左 46×69，中 45×69，右 45×69 逻辑像素。

## 像素与目视检查

所有 9×9 基础块内部同色，完整 PNG 为 17 色。`view_image` 检查确认中间蛋
仍为完整宽蛋形；眼环与蜡封仅在左缘局部可见，勾选偏左，虚线居中纵排，
斜带横穿蛋体且浅色、深蓝短横分区正确。未见渐变、混色、抗锯齿、模糊、
伪 3D、文字、水印、品牌或第三方角色。
