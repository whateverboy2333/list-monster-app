# 宠物蛋三视角 v6 最终提示词

## 输入职责

- `egg-turnaround-pixel-v5.png`：画布、三枚蛋轮廓、尺寸、位置、壳体填充、
  色板、像素尺度和接地影的事实源。
- 新造型参考图中间蛋：仅作为中间蛋表面花纹侧视投影的事实源。

## 编辑要求

只修改中间蛋表面花纹。左蛋和右蛋保持原像素；中间蛋继续保持完整、饱满的
45×69 逻辑蛋形及现有位置、壳色覆盖、材质明暗、外轮廓和接地影，不得恢复为
窄侧轮廓。

中间蛋花纹改为：

- 完整正面大眼移除，石灰绿眼环只在左上外缘露出狭窄局部弧带；
- 深蓝眼芯和白高光大部分隐藏，只允许极小边缘局部；
- 完整正面蜡封移除，橙红蜡封只在左下外缘部分可见；
- 绿色勾选移动到偏左中部；
- 深蓝虚线缝线位于上半部中轴附近并纵向排列；
- 米色斜带完整横穿蛋体并向右上倾斜；
- 浅色短横位于斜带偏左/中部，深蓝短横位于斜带偏右。

旧正面花纹移除处恢复为已有象牙壳色，不降低壳体覆盖或视觉重量。采用既有
受限色板、硬边粗像素和一至两档浅沙色接地影。禁止渐变、抗锯齿、模糊、
羽化、边缘混色、伪 3D、高清纹理、透明背景、文字、水印、品牌和第三方角色。
背景保持为均匀 RGB(254,250,236)。
