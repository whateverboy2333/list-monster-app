# 蛋形态三视角 v2 最终提示词

以原始三视角、v1 三视角和 `checklist-creature-pixel-evolution-v3-r3.png`
为视觉参考，生成一张 16:9 横向画布，只出现同一只清单怪兽蛋的三个视角。
这是定向修正，不重新设计角色。

- 左侧：明确的左前 3/4 视角，向观看者左侧旋转约 30–40°。青柠绿眼环、
  深蓝瞳孔、绿色对勾、米色腰带和橙红封印明显位于蛋壳左侧的朝前面；
  深蓝竖向缝线绕向该蛋最右侧远端。
- 中间：严格、明显更窄的侧视轮廓。眼环、对勾、封印只露出侧面薄片，
  腰带从侧面环绕。
- 右侧：方向相反的右前 3/4 视角，向观看者右侧旋转约 30–40°。眼环、
  对勾、腰带和封印明显位于蛋壳右侧的朝前面；缝线绕向最左侧远端。
- 左右两蛋不得复制；符号位置和缝线绕向必须呈镜像关系，清楚证明旋转方向相反。

保留象牙白蛋壳、青柠绿眼环、深海军蓝眼睛与缝线、绿色对勾、米色腰带、
橙红封印和彩色状态条。三个蛋等距排成一行且完整可见。

采用粗颗粒低分辨率像素画：大方形像素、阶梯曲线、硬边、极少量平涂色；
每种材质仅 2–3 个硬边色阶。禁止抗锯齿、模糊、渐变、喷枪、光滑高光和
柔和 3D 塑形。地面阴影仅用 1–2 个硬边颜色。背景为均匀暖象牙白，
接近 RGB(254,250,236)，四边保留充足空白。禁止文字、字母、标签、水印、
品牌、边框和额外物体。
