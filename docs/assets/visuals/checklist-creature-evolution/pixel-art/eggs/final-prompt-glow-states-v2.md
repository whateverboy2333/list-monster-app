# 蛋发光状态 v2 最终处理提示

以 `egg-glow-states-pixel-v1.png` 为唯一内容基准，不重新生成、不重排、不改造
角色或三个状态。保留三个正面蛋及其从左到右逐级增强的绿色至黄色发光表现，
并保留象牙白蛋壳、青柠绿眼环、深海军蓝眼睛与缝线、绿色对勾、米色腰带、
橙红封印和彩色状态条。

仅执行确定性像素化处理：先以最近邻缩至 192×108 逻辑网格，再使用与三视角
v2 完全相同的固定有限调色板做逐像素最近色量化，不使用抖动，最后以最近邻
整数放大 9 倍至 1728×972。所有边缘必须由大块方形像素构成；每种材质每个
状态仅保留 2–3 个硬边色阶，地面阴影仅 1–2 色。禁止渐变、柔光羽化、抗锯齿、
混合边、柔和 3D 塑形、文字、水印、品牌和第三方标识。背景固定为
RGB(254,250,236)，四边保留纯色空白。
