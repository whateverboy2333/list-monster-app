# Checklist Creature Pixel Evolution V2 — Final Prompt

Use case: style-transfer

Asset type: 清单怪兽 APP 四形态角色像素概念展示图 v2

Input images: Image 1 是人设与造型细节的原始参考；Image 2 是需要强化像素化的编辑参考。以 Image 2 的四角色数量、横向布局、进化箭头、比例关系和主配色为严格构图基准，以 Image 1 校准角色辨识度。只改变像素艺术的颗粒尺度、纹理简化和色阶表达，不改变角色身份或形态关系。

Primary request: 把 Image 2 重绘成真正原生低逻辑分辨率的粗像素画。画面应像先在约 320×180 或 256×144 像素的低分辨率画布上逐像素绘制，再用 nearest-neighbor 无插值整数倍放大。最终图中的每个视觉像素必须成为肉眼明显、规整、大小一致的方形色块；在角色身体内部、袍服、卷轴、阴影、箭头和背景边缘都能看到同一粗像素网格，而不只是外轮廓带锯齿。目标像素簇大约相当于最终显示尺寸中的 5×5 到 7×7 方块。

Composition/framing: 严格保留 Image 2 的横向 16:9 设定板布局：左侧小型悬浮初始体、中央卷轴人偶中间体、右上短壮拳斗型、右下宽袍祭司型；精确四个角色，全身可见，不新增、不遗漏。保留左到中的水平绿色进化箭头，以及中央通往右上、右下的绿色分叉箭头和方框勾选节点；箭头也必须以粗方形像素构成。

Character invariants: 四形态仍清晰保留米黄卷轴/绷带身体、深青黑粗缝线、深色脸部开口与酸橙绿发光眼睛、橙红蜡封圆徽章、绿色勾选、卷曲纸带手臂/肢体/尾巴。初始体保持小型兜帽卷轴团；中间体保持直立身体和对称卷曲纸带臂；拳斗型保持短壮比例、巨大圆厚拳套和双腿岔开的战斗姿态；祭司型保持宽大深青法袍、扇形纸页冠饰和正面米黄清单板，板上只有三个绿色方框勾选图形。

Style/medium: 16-bit / 32-bit 游戏角色设定图式的手工粗像素艺术，但信息密度服从低逻辑分辨率。使用硬边像素簇、清楚的台阶轮廓、大块块面明暗、选择性少量方格抖动。每种材质限制在约 3–5 个明暗颜色，纸张折痕用大块阴影而非细线，绷带层次用少量宽色带而非密集纹理，法袍纹样极简化，缝线粗而稀疏。所有曲线都由明显的方形台阶构成。

Pixel grid discipline: 整张画面共享完全一致的像素网格和像素尺寸；禁止局部出现更细的小像素。角色轮廓线厚度约 1–2 个逻辑像素，内部细节的最小宽度不得低于 1 个同尺寸逻辑像素。不要任何次像素细线、半透明抗锯齿边、柔焦光晕或平滑渐变。绿色发光只允许用 2–3 圈硬边方形像素色块表现。

Scene/backdrop: 简洁暖白或极浅米色背景，最多保留少量粗像素落地阴影；无道具、无边框、无装饰纹理。

Color palette: 统一受限色板，约 24–32 色覆盖整张画面；米黄、浅砂金、深棕、深青黑、墨绿/深青、酸橙绿、橙红为核心色。四个形态使用同一色板、同一像素密度、同一左上方块面光照。

Constraints: v2 的像素块必须比 Image 2 明显更大、更少、更规整；在正常显示尺寸下无需放大即可一眼看见内部结构由粗方格构成。保持彩色、可爱、高辨识度。无文字、字母、数字、标题、说明标签、品牌标识、水印、签名或第三方角色。

Avoid: 高清插画加像素描边；高清角色立绘；伪 3D 渲染；平滑渐变；抗锯齿；柔和笔刷；细碎高频绷带纹理；过密线条；微像素噪点；过量抖动；矢量曲线；水彩或油画；超低信息量火柴人；透明背景；裁切角色；改变布局或新增角色。
