# 「契响卷灵」进化族系 V2 设计说明

## 本轮修订结论

V2 保留“承诺被记录，完成产生回响”的族系设定、横向双分支关系与暖象牙／青柠／珊瑚／靛青色彩血统。定向重构诺卷仔和履契拳师：幼体从狐狸式纸兽改为抽象纸契生命，拳手从露出兽脸改为全头契纸包覆。

## 形态一：诺卷仔

- 阶段：幼年体
- 属性：契约／成长
- 性格：认真、亲人；会用纸页轻轻弹跳、卷曲来回应旅伴。
- 成长条件：写下一个真实、可执行的小清单，并完成其中第一项；持续收集履约回响后获得分支资格。
- 能力「回响墨迹」：完成一项清单时，身体侧面的勾选格亮起，将履约回响储存在卷曲页环中。
- 图鉴文案：它没有固定的脸和四肢，只有认真写下的承诺会让纸页折成一双明亮的眼睛。
- V2 造型：主体是多个有厚度的合同纸卷、交叠折页和缝装页束；两片宽阔不对称的页瓣承担情绪表达，不是尖耳；后方是短小卷纸环，不是蓬松兽尾；落地结构为卷边纸足，不是犬猫爪。
- 面部限制：无鼻、无嘴、无兽吻、无面罩花纹；两只青绿色发光眼直接嵌在交叠纸折之间。可亲感来自眼神、低矮弹跳姿态与页瓣倾角。

## 分支一：履契拳师

- 阶段：完全体·行动分支
- 属性：行动／连携
- 性格：爽快、守时，擅长把大目标拆成连续可完成的小步。
- 成长条件：诺卷仔在短周期清单中反复选择立即行动，积累多次连续完成的履约回响。
- 能力「连勾拳阵」：每完成一项，契纸缠带多亮起一枚勾印；连续勾印沿拳臂传导，强化下一次出拳与冲刺。中断不会扣除既有成长。
- 图鉴文案：没人见过绷带下的面孔，只有两束绿光会在下一项完成时骤然明亮。
- V2 造型：整个头部由多层羊皮纸绷带交错严密包覆，形成圆钝纸茧；不露口鼻、毛发、兽耳、皮肤或正常兽脸，仅在靛青暗缝中留下两只绿色发光眼。
- 拳击识别：巨型契纸拳套、错步压低重心与连续勾印保持行动分支的运动感；木乃伊神秘感来自纸带结构，不使用尸骸、血腥或惊悚元素。

## 分支二：万策卷贤

- 阶段：完全体·规划分支
- 属性：策划／积累
- 性格：沉静、耐心，擅长把遥远目标整理成清楚章节。
- 成长条件：诺卷仔长期维护分类清单，持续完成跨周期目标，并频繁回顾和整理历史成果。
- 能力「万策归档」：把历史完成沉淀为知识页，按主题装订成浮游书层，为下一阶段计划提供指引与守护。
- 图鉴文案：它从不催促旅伴，只把已经走过的路装订成书，让下一步变得更清楚。
- V2 造型保持：闭合书肩、展开页冠、层叠书袍、胸前主书板与页带长尾共同组成大学者；身体本身就是书本装订结构，不是普通动物穿袍。

## 三形态血统锚点

| 锚点 | 诺卷仔 V2 | 履契拳师 V2 | 万策卷贤 V2 |
| --- | --- | --- | --- |
| 生命之眼 | 纸折间的青绿大眼 | 靛青绷带暗缝中的绿色眼光 | 书页面部的青绿眼睛 |
| 清单符号 | 身体侧面三格勾选板 | 拳套、缠带与腰前勾印 | 胸前主书板三格勾选条 |
| 封印／装订 | 珊瑚胸印、靛青缝线 | 珊瑚腰封、靛青接缝 | 珊瑚胸印、靛青书脊 |
| 主材质 | 卷边合同、折页、页束 | 契纸绷带与契纸拳套 | 书本、书页与装订结构 |
| 主色 | 暖象牙、青柠、珊瑚、靛青 | 同源四色 | 同源四色加古金护角 |

## 进化合理性

- 诺卷仔的交叠纸卷可在行动分支中拉长为缠带、卷紧为拳套、包覆为纸茧头部。
- 同一批纸页可在规划分支中裁整为书页、缝合成书脊、层叠为书袍和页冠。
- 两条路线都由“完成记录”增殖材料，不以饥饿、惩罚或退化驱动成长。

- 通过：V2 为独立文件，未覆盖或删除任何 V1 交付物。
- 通过：幼体无尖耳、兽吻、黑鼻、狐狸面罩花纹、蓬松兽尾和写实兽爪。
- 通过：幼体第一眼呈现为有体积的活体合同页束，并用发光眼、页瓣和低姿态保留可亲生命感。
- 通过：拳手头部完全由羊皮纸绷带覆盖，仅在靛青暗缝中露出两只绿色眼睛。
- 通过：拳手的契纸拳套、压低重心和出拳架势清楚，无血腥、尸骸或惊悚表现。
- 通过：学者仍由书肩、页冠、书袍、主书板及页带尾组成，大学者身份清楚。
- 通过：三形态共享羊皮纸、绿色勾选光、珊瑚蜡封和靛青缝线，纸卷可向缠带或书页双向演化。
- 通过：画面仅有三个完整角色和一条清楚的 Y 形分支路径，无裁切、文字标签、水印、商标或既有 IP 标识。
