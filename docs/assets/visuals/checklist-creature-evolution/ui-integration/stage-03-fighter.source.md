## 响应式风险审计

- 375px：宽体角色等比缩小，当前任务尾注下移；时间线继续单列，成长数值换行。
- 200% 大字：角色与当前任务拆成上下两行；时间线元数据自然换行；互动与无压力说明进入滚动内容。
- 风险结论：低。信息结构为单列；主要风险是宽体角色与任务条争高，已规定保持角色完整并增长主舱。
