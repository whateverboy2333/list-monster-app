## 响应式风险审计

- 375px：双路面板各约 149px，短标签保持两行内；证据卡可维持双列，任务名最多两行。
- 200% 大字：双路面板、下一条件和证据卡全部改为纵向；角色独占主舱一行，分支说明放在角色之后。
- 风险结论：中。双列是阶段语义核心，但在 200% 大字下必须转为等权纵列，不能缩字或让一侧先折叠。
