# XP Rules v0.1.3

## 基本原则

1. 怪兽成长必须来自真实任务行为。
2. 抚摸、打开 App、桌宠互动、小组件查看、引导自动完成不产生正式 XP。
3. 所有 XP 发放必须写入 XP ledger，并通过 `sourceEventId` 幂等去重。
4. 每日正式 XP 上限为 125。累计完成奖励 +20 计入每日上限；长期任务整体达成 +50 不占每日上限。

## 任务完成经验

| 行为 | XP |
|---|---|
| 当日第 1-5 个普通任务完成 | +10 / 个 |
| 当日第 1-5 个高优先级任务完成 | +15 / 个，替代 +10 |
| 当日第 6-10 个可奖励任务完成 | +5 / 个 |
| 当日第 11 个起可奖励任务完成 | +1 / 个 |

规则：

1. 只有 `Task.rewardEligible = true` 的完成事件可产生 XP。
2. 普通 `SubTask` 默认不产生 XP。
3. 引导自动完成“给怪兽起名字”不产生正式 XP。
4. 高优先级 +15 只适用于当日第 1-5 个可奖励任务；第 6 个起进入递减规则。
5. 同一 `task_completed.eventId` 只能发放一次 XP。
6. 完成撤销通过 `xp_reverted` 产生冲正记录，不直接删除原 XP ledger。

## 今日任务激励

`daily_clear` / 今日通关已废弃。

MVP 使用今日任务激励：

| 当日可奖励完成数 | 提示 |
|---|---|
| 3 | 小试身手 |
| 6 | 收获满满 |

该机制只提供正向激励，不要求用户清空今日任务。

## 前日反馈

第二天用户打开 App 时，系统根据前一天完成情况生成 `daily_task_summary`，以正向语气反馈用户昨天完成了多少任务。

## 累计完成奖励

累计完成超过 3 天时触发 `cumulative_active_reward`。MVP 固定第 4 个活跃日一次性 +20 XP，计入每日正式 XP 上限；后续版本再评估 7 / 14 / 21 天阶梯奖励。

## Streak

定义：连续完成任务的天数。

活跃日：用户本地时区内完成至少 1 个 `rewardEligible = true` 的任务。

规则：

1. Streak 使用用户本地时区，不考虑 VPN 等网络位置。
2. `streak_break` 是内部事件，不惩罚用户。
3. Streak 的产品目标是帮助用户养成习惯，而不是制造压力。

## 长期任务达成奖励

长期任务本体不能直接完成。只有所有拆解任务汇总达成时，触发 `longterm_achieved`。

| 行为 | XP |
|---|---|
| 长期任务整体达成 | +50 |

规则：长期任务取消 / 放下不产生 XP。
