### 变更背景

### R2 交付

- 新增 `stage-00-egg-r2.png`，443×980，以及对应 `.source.svg`、`.source.md`、`.meta.json`。

- 初诺契茧身份、2/3 三方格、下一点亮条件、三阶段轨迹、两条回响和无压力说明保持不变。

### 影响范围

## [v0.5] - 2026-08-05

### 变更背景

用户指出已通过 QA 的旧蛋页中蛋体观感偏纵向拉长。核对后确认角色本身没有生成式改形，但窄长纸色观察窗放大了纵向轮廓；本轮以非覆盖式 R1 修正角色显示尺寸、光晕和视觉落点，不扩大到后四阶段。

### R1 交付

- 新增 `stage-00-egg-r1.png`，443×980；旧 `stage-00-egg.*` 全部保留为历史记录。
- 新增 `stage-00-egg-r1.source.svg`、`stage-00-egg-r1.source.md` 与 `stage-00-egg-r1.meta.json`，记录源裁切、alpha 包围盒、显示变换、素材／输出哈希和导出尺寸。
- 新增 `stage-00-egg-r1-comparison.png` 及可重渲染 SVG，左旧右新，仅用于 PM 与用户评审。
- R1 取代旧蛋页，成为后续 Craft 实现的初诺契茧基线。

### 比例与构图修正

- 最终蛋有效裁切与 alpha 包围盒均为 480×720，宽高比 `0.666667`；页面显示盒为 124×186，宽高比 `0.666667`，差异 `0.000%`。
- 276,912 个非透明像素已与 `egg-glow-states-pixel-v3.png` 对应坐标逐像素核对，RGB 差异为 0；未重画、重着色、镜像或非等比缩放。
- 旧稿有效蛋体显示约为 132×198；R1 等比收至 124×186，高度减少 12px（约 6.1%）。167×220 窄长观察窗改为 218×152 短宽光晕，并增加横向落地影稳定重心。
- 蜡封、绿光、缝线与底部卷轴阴影完整保留；身份、2/3 进度、点亮条件、孵化轨迹、两条回响及无压力语义不变。

## [v0.1-draft] - 2026-07-29

### 变更背景

现有 MVP Beta 以白底、薄荷绿卡片、Material 默认控件和蛋形占位为主，用户首先感知为普通清单工具，怪兽成长缺少主场、可见因果与长期陪伴感。本轮执行 L1 完整设计，目标是把原创电子宠物设为产品主角，把真实任务完成转译为投喂、训练、共鸣反馈。

### 设计方案

- 推荐 A「掌上回响站」：深墨栖息舱 + 暖纸任务台 + 青柠/珊瑚/青色信号。
- 定义原创回响兽“小单”：非对称卵石种子体、珊瑚左鳍、青色右耳、方形回响核、点阵脸。
- 保留“今天 / 长期 / 怪兽 / 我的”四项一级导航，重排今日页与怪兽页信息层级。
- 建立 Primitive / Semantic / Component 三层 Token。
- 定义“完成任务 → 真实 XP → 小单动作反馈 → 进化进度”的本地优先闭环。
- 明确“能量/回响”只作叙事，不得新增第二套账本；抚摸不产生 XP。
- 定义删除二次确认、明确后果、成功通知、8 秒撤销和长期恢复区。
- 现有 UI 的迁移、合并或隐藏均列为待用户/PM确认，本轮不执行删除。
